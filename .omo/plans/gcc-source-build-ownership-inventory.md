## Capture mechanism decision and review gate

Use **Linux ptrace syscall-entry/exit observation with fork/vfork/clone/exec/exit event following**, outside the build processes, as the proposed primary capture mechanism; do not change CC/CXX/AR/LD, PATH, configure argv or Makefile commands to insert a wrapper into the production build. The implementation must select and pin an existing inspectable syscall/process collector under the appropriate runtime/native authority. This plan does not claim such a qualified collector is already available or authorize creating/launching one. Gate the collector interface and qualification before a production build. The runtime owner must bind the collector binary/source/ABI and required ptrace options/capabilities to its isolated control plane, following every thread and descendant from the already stopped root. Attach-after-start and best-effort sampling are rejected. Kernel/run/descriptor provenance and a successful control-plane terminal record are required before Kotlin accepts trace completion; a self-hashed producer file cannot mint that authority.

The required collector contract is precise: lossless successful/failed execve/execveat and fork/vfork/clone/exit coverage; exact argv/environment and cwd/root/namespace/executable identity at exec; descriptor inheritance/chdir/fchdir/open/openat/openat2/dup/close/read/mmap/write/rename/link/unlink relationships sufficient to identify every consumed/produced file version and response/script/linker input; authenticated initial root tree and terminal state; parent-child and phase roots; no detached descendant, dropped/overflowed event, unobserved file mutation or unsupported I/O path. Pin executable/runtime/kernel/capabilities and collector bytes/configuration; retain an authenticated collector-owned completion receipt. Trace stdout/stderr or a caller's JSON is not that receipt. Mutable generated files need a content-addressed consumed version before reuse/removal, not a terminal-tree hash. Concurrent read/write races or unversioned input access refuse completeness. Account for mmap-backed writes, descriptor passing and inherited file descriptions; unsupported io_uring/asynchronous I/O or an unobserved transfer path refuses the operation rather than disappearing from the access set. Snapshot/hashing happens against retained stable file versions under the collector-controlled stop boundary; tracing pathnames and hashing a later file is insufficient.

A rendered `strace` log, Bear/interposition output, Make verbose log, compdb or compiler wrapper is **insufficient alone**. A text tracer would need a reviewed complete lossless decoding/provenance profile satisfying every requirement above; truncated exec/env strings, unsupported syscalls, setuid escapes and missed children fail. Read-only planning can start with exact raw event fixtures and validators while this collector capability is established through its owning runtime contract. Do not silently switch to a weak log when collection is blocked.

Observation can affect timing or parallel completion. Qualify scheduling and instrumentation noninterference on proportional authored multi-process compiler/archive/link/generated/response fixtures, then perform one complete authenticated captured clean build using the identical original command/env/virtual paths. That actual build must reproduce the exact pinned rich/stripped bytes and complete action/input/file-version closure. Follow it with two full independent deterministic raw-to-canonical verification replays as specified in step 5. Preserve separate instrumentation identity and provenance; no config mutation is hidden behind matching output. Output equality is necessary, not sufficient: independently reconcile complete process/action/file closures and actual tool identities too. Unknown capture semantics block qualification. An additional full captured build or unobserved driver baseline is required only when a concrete remaining failure, instability or unresolved observation justifies it; record that specific reason and expected resolving evidence before running it.

The original build lacks a requested linker map. After capturing its genuine leaf linker invocation and exact immutable inputs, run a **separate trusted oracle-only link evidence replay** with the exact pinned linker, argv/cwd/env and inputs, adding only reviewed map/selection diagnostics (for GNU ld 2.44, freeze exact option/grammar in the policy). Use a fresh scratch tree exposing the same virtual output path. Require complete output bytes equal the captured linked driver before using the map. Hash diagnostic tool/options separately; parse its selection/discard/provider/section-contribution records and independently check them against ELF sections/relocations/archives. A map from another link or a name/size join is refused. If supported diagnostics cannot prove the required contribution, implement the missing bounded ELF relocation/contribution proof; do not infer it from names or code equality.
