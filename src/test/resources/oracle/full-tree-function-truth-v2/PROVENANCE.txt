KNOWN PYTHON PRODUCER/VALIDATOR CONTRADICTION AND EXCLUDED CASE

This vector intentionally has no coalesced DWARF-only RVA. In the captured
Python producer, oracle/full_tree_function_truth.py lines 454-457 increment
coalescedEmittedRvas only inside "if elf_record". The validator at lines 255-256
increments the same count for every coalesced truth function, including an
excluded DWARF-only record. A coalesced DWARF-only case therefore makes that
producer reject its own output. Excluding the case is only a migration-fixture
workaround; it is not a semantic decision and must not be copied into Kotlin
production policy.

  import json
  from pathlib import Path
  import shutil

  from oracle.full_tree_function_truth import reconcile_full_tree_function_truth

  root = Path('src/test/resources/oracle/full-tree-function-truth-v2')
  scope_payload = (root / 'scope.json').read_bytes()

  inventory = json.loads((root / 'inventory.json').read_text(encoding='utf-8'))

      Path('/tmp/full-tree-function-truth-v2-replay-a'),
      Path('/tmp/full-tree-function-truth-v2-replay-b'),

      if output.exists():
          shutil.rmtree(output)
      reconcile_full_tree_function_truth(
          scope=scope,
          scope_sha256=hashlib.sha256(scope_payload).hexdigest(),
          inventory=inventory,

          observation_root=root / 'observations',
          output_root=output,
      )
  for expected_path in sorted((root / 'expected-truth').rglob('*')):

          expected = expected_path.read_bytes()

          assert (outputs[1] / relative).read_bytes() == expected
