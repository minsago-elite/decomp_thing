The decoded expected bytes in this directory were emitted by the retired Python

PURPOSE AND METHOD

On 2026-09-02 (Asia/Seoul), the Kotlin end-to-end test fixture rebound its fixed
embedded ELF to authenticated test controls, derived the ELF function index from
the raw ELF, derived and validated both DWARF observation shards, published the
exact generic bounded observation run, and invoked the real Kotlin raw-input
function-truth path. A temporary export hook captured those already authenticated
intermediates and the Kotlin output; the hook was removed before this fixture was
committed.

The captured intermediates were then passed to the historical Python v2
reconciler twice in an offline migration replay. Both Python trees had exactly
the same four-member set and bytes as each other and as the Kotlin tree. The
checked-in base64 payloads encode the Python output from that replay. The normal
test regenerates all inputs from the embedded raw ELF with Kotlin and compares
the Kotlin publication to these decoded bytes; it never runs Python and never
admits the expected bytes as inputs.

REPLAY SHAPE

The exact replay loaded the captured scope bytes and used their SHA-256 as
scope_sha256, loaded the captured inventory JSON, and called
reconcile_full_tree_function_truth with the captured elf/functions.json and
observations directory. It did so into two fresh output directories. A recursive
map of relative file name to bytes was then built for both Python outputs and the
captured Kotlin output; equality of all three maps was required before encoding
the four Python members stored here.
