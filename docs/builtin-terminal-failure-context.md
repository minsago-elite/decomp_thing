# Failure-only terminal launch context

The shared terminal broker keeps the original safe protocol error, authorization audit, overflow policy,
reservation/cleanup behavior and native checks. A launch refusal additionally retains an internal display
projection at its exact existing audit sequence. The public AcpTerminalAuditRecord/evidence shape is unchanged;
the supplemental projection is not included in provider results or wire/archive authority.

Capture visits at most eight direct causes through exact known exception classes. Unknown subclasses remain
unavailable without invoking their cause getter; the closed native witness is a leaf. The authored accessor
control asserts zero getter invocations. Capture never reads arbitrary messages, stacks or suppressed arrays,
retains no Throwable, and recognizes only fixed categories/errno and already captured sealed mount-event
witness/admission records with closed ASCII grammar and strict length limits. Construction/accessor failure
leaves the projection unavailable without replacing the original refusal. The last eight projections are
retained under the existing audit lock/cap; formatting is bounded to 4,096 ASCII characters. No native query,
clock/deadline read, host observation, retry, authorization or cleanup decision is added by diagnostics.

The existing built-in feedback assertion appends this context on the same fixture/dispatcher path. Every
original native invocation, assertion condition, timeout and resource/output limit is retained. Eight new
controls use authored Throwable/record data only; the existing closed witness is constructed with its scalar
constructor, without a sandbox, broker, process, host query, provider or model session.

The existing DENIED/LAUNCH_FAILED observation remains unclassified until its actual retained context establishes
more. This source change is not a causal fix, cleanup proof, permission to retry, new runtime qualification or
completion of #784/#74. Original full criteria and all authentication/privacy/native-context holds remain binding.
