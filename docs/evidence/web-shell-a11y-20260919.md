# D3 accessible shell navigation evidence (#497)

Scope: the public SPA shell in a packaged application, including a nested
deployment path. This is implementation and local verification evidence, not a
production accessibility certification or a full WCAG audit. The dependency
contracts and broader end-to-end journey remain owned by #167 and its other
children.

## Acceptance mapping

- Page titles: route-specific document titles for Jobs, Upload, Runtime, job,
  run and history views. The packaged gate checks Jobs and Upload titles.
- Primary landmarks: one semantic `main` landmark in the DOM and Chrome
  accessibility tree; the packaged gate checks both.
- Skip navigation: the keyboard-focused skip link becomes visible with an
  outline; Enter moves focus to `main` on the nested deployment path.
- Focus movement: after initial render, client navigation, direct reload,
  lazy-route completion, Back and Forward, focus lands on the route's `h1`.
  Query-only history and background rerenders retain the user's focus. During
  asset-recovery notices, heading focus does not scroll the notice away.
