# Structural global and type recovered projection

This slice for #682 accepts typed recovered observations for `global.*` and `type.*` v1 dimensions, plus the frozen v1 `function`-owned `global.reference` dimension. It emits rows in the existing `recovered-structure` v1 entity/fact shape. It does not change the frozen schema, loader, scorer, oracle contract, or production admission rules.

The input is an untrusted observation DTO, not an adapter for `ProgramModel` display strings. A future capture adapter must supply an opaque stable entity ID, a real v1 dimension and slot, an explicitly typed source value when recovered, and evidence locators; this DTO itself does not authenticate those claims. The projection never parses names or declarations. Its recovered state vocabulary has only `recovered` and `recovered-unknown`; oracle visibility remains controlled by the separately trusted oracle. A recovered input cannot mark an oracle fact unobservable or remove an entity from the oracle denominator.

Every supplied entity is retained in the result census. Entities with one or more valid observations are represented in `projectedEntities`; entities with no observed dimension/slot rows are listed in `unprojectableEntityKeys`. `entityCensusConserved` checks conservation of only the supplied entities, and `allInputEntitiesProjectable` is false while that partition is nonempty (and for an empty input). `requireAllInputEntitiesProjectableForFixtureScoring` rejects an empty or unprojectable supplied census. The projection does not fabricate unknown fact slots. This result cannot prove that the caller supplied every entity in the actual population.

This projection is not an authenticated snapshot, not a production `recovered-structure` artifact, and never enables production scoring. Passing its fixture-only guard is not production authority or proof that no entities were omitted. A future production handoff needs a versioned population envelope that joins the complete #39 entity population and independently trusted oracle visibility with recovered observations, including zero-row census entities. The typed Ghidra capture source and authenticated admission remain separate work; passive `ProgramModel` strings do not satisfy them.
