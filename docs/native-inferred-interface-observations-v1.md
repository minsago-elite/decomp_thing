# Raw inferred interfaces and native type graphs v1

This component implements the raw observation scope in #1746. It adds typed HighFunction observations and immediate referenced datatype relationships to the listing foundation in #1737. The component grants no oracle, scored, INTERFACES or release authority. #680 still requires owned capture, independent source evidence, versioned semantic normalization, complete populations and production replay.

## Separate observations

`ExportInferredInterfacesV1` is a fixed compiled Java collector dispatched by `RunBundledExports`. It uses the bundled dependency and one serial `DecompInterface`; there is no installed Ghidra or external headless prerequisite. Existing C/model exporters, listing-v1 bytes, existing invocation profiles and production capture behavior are unchanged. A later owned runtime operation must select this collector explicitly.

The caller supplies exact input, exporter, bundled archive, listing collector, inferred collector, type-graph helper, wrapper and native decompiler commitments, the frozen model, an existing listing directory and an absent private output directory. The main collector and its type-graph helper have separate exact source commitments in both the document and manifest; changing either invalidates the expected binding. These are byte commitments, not authentication of a caller or runtime. A later genuine capture must also bind the complete compiled runtime/class tree. The collector first reruns the existing listing collector against the same Program/model and requires byte-identical listing and manifest snapshots. It then emits all listing graph roots before any inference. The native Program modification number and all model/listing file identities are rechecked before publication. No inference is committed back to the Program.

Every native internal and external function receives one ordered outcome, including thunks, unsupported bodies and failed inference. A complete current listing census does not prove that all binary functions were recovered. Zero/default listing parameters and inferred parameter counts remain raw observations; neither establishes source arity. The reader preserves the listing reader's complete model/native projection, including scalar-coordinate ambiguity, missing model matches and external/off-space/unmatched native entries.

Successful records preserve public FunctionPrototype fields, return type/storage and the full LocalSymbolMap parameter census. Each parameter retains its inference index, category index, nullable HighParam slot and HighVariable state, native symbol ID, type/name locks, hidden-return and `this` flags, first storage mapping and first-use coordinate. The local symbol and prototype counts remain separate with an explicit consistency flag. Raw result completion/validity/timeout/cancel/start-failure flags and diagnostic remain distinct; a warning does not automatically discard an available HighFunction.

Listing formal/effective root roles and inferred native-type roles are distinct namespaces. They are never joined by parameter position. Public HighSymbol storage exposes the first mapping; it does not establish full lifetime/range coverage or machine entry allocation. Ordinary decoded storage can have `forcedIndirect=false` without proving direct value passing. The inferred formal/effective relationship and private prototype flags remain `unavailable-native-api`. Missing or unsupported observations do not become false, zero or an empty source parameter list.

## Referenced type graph

Graph node IDs identify first encounters of native datatype objects within exactly one `(channel, functionOrdinal)` scope. They are not source type identities, globally stable IDs or semantic equivalence. Native pointer recursion and repeated references are represented as explicit backedges/reused nodes. Names, display declarations and `isEquivalent` never merge types.

Typed node and edge records preserve integer signedness, floating representation, pointers, arrays and extents, typedef targets, structure/union component ordinals/offsets/lengths, packing and alignment modes, bitfield declared/effective widths and raw offsets, enum signed-state/count, and function-definition return/convention/variadic facts. Undefined components are observed filler, not proven source padding. DataOrganization separately records target scalar/pointer sizes, endianness, alignments and bitfield packing context.

The pinned FunctionDefinition API lacks a count accessor before its allocating argument-array getter. Its argument population therefore remains `unavailable-bounded-count-api`; it is never treated as empty. Typedef settings have the same explicit limitation. Enum contents are not captured, although raw count/signed state are retained. Unsupported native kinds keep explicit nodes; layouts never establish C++ triviality, invisible-reference semantics, nominal/ODR identity, ownership or shared source-use membership. This is bounded native representation, not complete source type closure.

## Bounds and publication

One aggregate component envelope includes model, listing manifest/observations and new manifest/observations within 1 GiB. Temporary listing comparison charges its actual output and simultaneously live type spool before each write against the remaining allowance after retained inputs, reserving 64 KiB for its manifest. Spool capacity releases only after deletion. This accounts for a comparison that grows beyond a stale frozen listing before the equality check rejects it. Charged bytes are logical file bytes, not filesystem blocks; the enclosing finite scratch lease still owns filesystem occupancy and inodes. This ceiling is not additional capacity on top of a future native capture envelope. Limits include a 512 MiB model, 64 KiB manifest, 131,072 functions, 1,024 parameters per function, one million inferred parameters/storage pieces, 64 pieces per storage, 256 spaces, 4,096 UTF-8 bytes per metadata string and 1 MiB per record. The graph shares 200,000 nodes, one million edges, depth 64, 4,096 immediate children per node and five million charged traversal steps across every scope. Counts are checked before requesting arrays, child traversal or record serialization. A charged dependency preflight and memoized metadata-depth check run before native recursive layout getters; malformed by-value cycles and deep reused typedef chains cannot bypass the bound. Successful graph work is independently rederived as root calls plus three times nodes plus three times edges plus one DataOrganization step and its alignment rows. A bound failure invalidates the capture rather than publishing a smaller successful population.

The additive listing `collectWithStagingBudget` entry point returns its peak charged bytes, including the manifest reservation. Existing listing callers and wire fields are unchanged. The inferred `collectWithByteLimit` entry point only tightens the existing hard ceiling; the fixed wrapper uses the unchanged default. Both collectors' changed source hashes remain explicit bindings in regenerated observations. Authored bundled controls check exact/one-over staging peaks, byte equality with the ordinary listing path, and cleanup before publication when a stale smaller listing rerenders beyond its remaining allowance.

Inference uses explicit `decompile` simplification, syntax trees on, C output off, 500,000 instructions, a 50 MiB native payload ceiling, 1,024 jump-table entries and one attempt per supported function. Each attempt receives at most 60 seconds clipped to a 120-second collector lifetime starting before input hashing. The lifetime is a component refusal bound, not a production resource-profile change. Existing outer isolated worker heap/cgroup/PID/disk/deadline limits remain required. The engine is stopped/disposed on every exit.

Output is staged privately, made read-only and published with a committing manifest only after successful conservation and identity checks. The reader checks canonical closed records, exact bindings, graph references/scope/order, function/root/parameter/storage/disposition conservation and the complete listing population. Its callbacks are speculative until successful return. Ordinary validated bytes cannot recreate a live admission capability.

## Evidence and remaining gates

The [pinned source/API census](native-inferred-interface-observations-v1-api-sources.json) records the bundled source archives and exact entries reviewed for this component. Authored fresh-JVM controls run real bundled decompilation of machine functions and compare listing and inferred observations without writeback. Typed graph controls use real native datatypes, with guarded test doubles only to demonstrate pre-access limit refusal. The authored SysV control demonstrates a real listing/inference difference and transport of a seventh integer stack argument. The pinned decompiler reports eight SSE parameters for a function that also reads the authored ninth SSE stack position; the observation preserves that omission and does not fill it from source knowledge. A separate actual Windows capture observes `this` and hidden-return HighSymbols. Its aggregate parameter has listing forced-indirect storage while the decoded inferred storage reports false; both raw channels remain separate and the inferred meaning stays unavailable. These controls establish component behavior; they do not establish production ABI accuracy.

Remaining work includes an authenticated new runtime/intent and owned capture that freezes the exact paired model/listing/inferred bytes after worker absence, then separately accesses independent oracle evidence. Selection/mapping must use that exact model, not another same-input export. Structural-interface-v2 must retain formal/physical/inferred slot relations, unknown source arity, independently authenticated negative coverage, passing modes and whole-call allocations. Equal classes, sizes or alignments are insufficient ABI equivalence. The #693 function-signature threshold cannot be replaced by a fact micro-average. #692 and #1513 retain their full population and source-ownership obligations. INTERFACES registration and production threshold claims remain unavailable.
