# GCC ABI source obligations and scalar enrichment (#692)

This checkpoint implements physical source coverage and lossless attribute enrichment under the reviewed admission-v1 contract. It establishes no semantic function, storage or shared-type denominator. Issue #692 remains open. The full plan still requires semantic identity, complete required type closure, authenticated translation-unit/build ownership, recovered model admission, independent reconciliation, sealing and qualification.

`AbiPopulationSourceObligations` enumerates each physical DIE and each reference, retaining source ordinals, parent, depth and child flag. Its closed registry covers all 37 observed tags and nine reference attributes. This version admits only the observed retained-target/ref4 state, enforces the 32-bit operand width and refuses unsupported/missing/out-of-range state claims pending a reviewed policy. All edges, including siblings, retain `interpretationRequired=true`; forwardness is not a complete sibling scope proof. GNU template/formal packs receive interpretation obligations. No tag, cycle, address, name, connected component or physical CU is promoted to an entity, alias, exclusion or source owner.

`AbiPopulationSourceVerifier` independently replays source coverage and the proposed obligations. It reconstructs scope ancestry, globally ordered nonoverlapping physical attribute spans and CU coordinates, CU-relative reference target membership, typed relation roles and source/decision conservation. Primitive coordinate arrays support bounded target lookup. Two replay fingerprints reject changed typed source data between passes. The verifier does not call the builder. It does not replay individual null-marker bytes or establish complete semantic scope/member cardinality; those require the authenticated parser and later closure proofs.

`AbiPopulationScalarEnrichment` preserves every parsed attribute in abbreviation order, including duplicate names, signed/unsigned/wide constants, exact expression/string bytes, indexed and external references, form metadata where retained by the parser, and explicit uncaptured payloads. The shared parser payload wrappers expose a bounded defensive-copy operation that checks private payload size before allocating, without exposing mutable backing arrays. Its independent verifier compares each row against the typed source parser record without calling the producer. String-section offsets remain references, indexed addresses remain indices, and range/location lists remain references; they do not become invented strings, addresses or complete ranges. These observations are not semantic truth classifications. Unsupported/ignored payloads remain capability gaps.

Inputs must come from held authenticated artifact replay. These internal components do not authenticate arbitrary caller-supplied sequences or replace the existing stable-descriptor/scanner boundary. A later ledger manifest must bind every source coordinate to its exact authenticated input, schema, policy and tool roots.

## Verification and limits

Thirteen focused fixture tests cover missing/extra/reordered source obligations, forged role/target/parent, unknown tags, GNU packs, unchanged identity uncertainty, row/work limits, scalar substitution, duplicate attributes, signedness, unsupported payloads and payload bounds. Nine belong to source obligations and four to scalar enrichment. They are fixtures, not thirteen retained GCC controls. Allocation counters verify that oversized 8 MiB inline/expression payloads reject before a defensive copy in both producer and verifier; returned bounded copies cannot mutate retained payloads.

`GccAbiPopulationSourceRetainedReplay` is a test-side diagnostic main. With `<artifact.zip> <physical-census.json>` it authenticates the pinned retained ZIP/census and every physical shard, verifies canonical bytes, then independently reconstructs all 696,357 DIE and 800,159 reference obligations. With `--rich-only <gcc-driver.full> <repository scratch>` it opens the exact rich ELF through `StableControlFile`, checks its 20,713,760-byte/SHA256 identity and unchanged descriptor, and rescans all 111 CUs. Each DIE's scalar observations are immediately independently compared before disposal. The retained and fresh input identities are explicit in the main; arbitrary substitutes fail.

The fresh rich replay observed 2,782,106 attributes, including 33,900 uncaptured or unsupported payload observations. Its existing parser charged 3,795,244 steps against the unchanged default `FullTreeControlLimits.maximumDwarfParseSteps=100,000,000`; per-CU modeled retained limit remains 64 MiB. The diagnostic observes that existing parser counter through reflection; it does not alter its value or limit. Scalar payloads total 150,654,197 characters under the existing 512 MiB diagnostic ceiling. This is a payload-character measure, not canonical artifact byte size, complete memory accounting or semantic completeness.

The source component defaults are at most 1,000,000 DIE rows, 5,000,000 **row/edge visits**, 100,000 references per row, 4,096 locator characters and depth 64. Fixture overrides only tighten these limits. Scalar byte payloads are at most 1 MiB per attribute, stricter than the parser's 16 MiB default. The source verifier's two passes charge 2,993,032 row/edge visits; the diagnostic's third builder pass makes 4,489,548 visits. These counters do not include parser/decoder operations, binary-search comparisons, hashing, string work, canonical processing or output. They are not an admitted aggregate work profile. Existing canonical validation's 4,193,523 work count must not be combined with these passes and represented as fitting one 5,000,000-step budget. No existing profile limit was raised.

All retained replay paths, logs and compiler caches used for this checkpoint stay under repository roots. Short checks use cached Kotlin 2.4.0 compiler/runtime and exact existing `wf_ce026d1b-c24-51` compiled dependencies; this is not an exact-head Gradle build or Actions qualification. A full aggregate parser/emission/replay/index/string/deadline/RSS profile remains unqualified. `-Xmx512m` is not an RSS measurement.
